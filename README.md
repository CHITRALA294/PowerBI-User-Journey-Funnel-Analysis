# User Journey Funnel Analysis Dashboard

## Project Overview
This Power BI project analyzes the user journey from website visit to purchase. The goal is to identify major drop-off points in the funnel and provide actionable recommendations to improve conversion.

## Funnel Stages
Visit → Product View → Signup → Add to Cart → Checkout → Purchase

## Key Metrics
- Total Visitors
- Total Purchases
- Overall Conversion Rate
- Total Revenue
- Average Time Spent

## Dashboard Pages
1. Executive Overview
2. Segment Analysis
3. Drop-off Diagnosis & Action Plan

## Key Insights
- The overall conversion rate is 5.9%.
- Out of 1,200 visitors, 71 users completed purchase.
- Major drop-offs were observed during the signup and cart stages.
- Segment analysis helps compare conversion performance across device, traffic source, location, and age group.

## Recommendations
- Simplify the signup process.
- Improve mobile checkout experience.
- Show delivery charges earlier in the cart journey.
- Improve landing page relevance for low-converting traffic sources.
